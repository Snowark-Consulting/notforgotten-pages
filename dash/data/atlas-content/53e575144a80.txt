## Learnings
1. **Gate 8b is essential** — paragraph spacing must be enforced at code level, not caught in manual review. The platform collapsed visible whitespace in chat rendering, creating a false impression of incorrect formatting. Code blocks preserve whitespace for Founder review.
2. **Self-contained send scripts work** — cross-module imports between `send-email.py` and `state-transition.py` are fragile. The self-contained approach ensured clean execution.
3. **Five review rounds before send** — the process works. Discovery over closure. Simple over analytical. Verified over assumed. Every round improved the output.
