# PandaDoc Extractor Syntax Defect + Chrome CDP Not Running — 2026-09-02

> An unreachable dead-code fragment broke the extractor, and Chrome was never running for the CDP path it depends on.

Related: [[LEARNINGS]] (`learnings/LEARNINGS.md`), [[Learnings Catalogue]] (`learnings/catalogue.md`).

## 2026-09-02 — pandadoc-extract.py syntax defect + Chrome CDP not running (quotes-pulse #43131)
**Symptom:** pandadoc-extract.py crashed with `IndentationError: unexpected indent` at line 99 (orphaned dead-code fragment after `return data` in `extract_from_pandadoc()`, leftover from a removed DOM-fallback block). Then, once fixed, Chrome CDP on :9222 was NOT running; when started without `--remote-allow-origins=*`, WebSocket handshake returned `403 Forbidden — Rejected an incoming WebSocket connection from the http://localhost:9222 origin`.
**Cause:** (1) Botched earlier patch left unreachable lines inside the function body. (2) No persistent Chrome running at pulse time on this box. (3) Chrome ≥136 rejects CDP WebSocket connections from non-allowlisted origins by default.
**Fix:** (1) Removed orphaned lines 99-113; script compiles. (2) Start Chrome before extraction: `/usr/bin/google-chrome --headless=new --disable-gpu --no-sandbox --remote-debugging-port=9222 --remote-allow-origins=* --user-data-dir=/tmp/chrome-cdp-pulse --window-size=1400,2000 about:blank` (background). (3) Use fresh-tab AX pattern (poll to ≥10,000 chars + scroll pass) rather than the on-disk script, which stops at >200 chars and never scrolls.
**Source:** 2026-09-02 QPaint #43131 Mark Hughes intake. Skill note added to quote-intake SKILL.md.
