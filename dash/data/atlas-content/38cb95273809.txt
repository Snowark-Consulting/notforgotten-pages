# SOPs Index — Not Forgotten Systems

> Canonical registry of every SOP in the vault. One line per procedure. Index says *what* and *where*, never *how*. Three hops: Registry → sops-index → SOP skill/file.

## How to use

1. **Agent boots** → loads this index. Scans the Standing Rules table for universal constraints.
2. **Task triggers a procedural SOP** → loads the skill by name. Full procedure + pitfalls load on-demand.
3. **New SOP added** → add a row here AND register in `Agent/SOPs.md` (Skill Registration rule). Lint checks for index drift weekly.
