## IMPLEMENTATION NOTES

1. **No UNION of Prospects + QPaint Pipeline.** They remain separate data populations in separate dashboard sections.
2. **All hardcoded placeholders removed.** Pipeline bar, percentages, status strings — all dynamic.
3. **Freshness timestamps** on every section with source status.
4. **Failed source → display "DATA UNAVAILABLE"** not stale cached value.
5. **Quotes table dependency eliminated entirely.** Replaced by QPaint Pipeline for value data.
6. **"Tradies" reference removed** — no longer needed.
7. **dashboard-update.py** will need significant restructure (3-section layout, multiple data sources).
