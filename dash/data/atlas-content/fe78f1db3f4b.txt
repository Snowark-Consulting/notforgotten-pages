## Critical Architecture (DO NOT RECREATE FROM SCRATCH)

### Canonical Send Authority

**Single source of truth for customer Gmail send:** `scripts/canonical-send.py`

- 11-gate pipeline: Classification → Idempotency → Approval → Pre-Send → Duplicate → Gmail → Verify → Messages → Evidence → State → Read-Back → Reconciliation
- All gates fail closed (UNKNOWN = BLOCKED)
- Gate -1 (Classification) fires BEFORE token loading
- 15/15 regression tests: `python3 scripts/canonical-send.py test-gates`

**Do not create alternative send paths.** Any customer email must route through `canonical_send()`.

### Send Classification

| Mode | Journey | Gates | Addresses |
|---|---|---|---|
| CUSTOMER | Required | All 11 | Production |
| SYSTEM_INTERNAL | Optional | Approval gates | Production |
| TEST_NON_PRODUCTION | Optional | Approval gates | @test.com/@example.com only |
| Unknown | BLOCKED | — | — |

### Founder Approval

- Path: `data/founder-approvals/pending/` → `data/founder-approvals/approved/`
- `create_approval_request()` → status = APPROVAL_REQUESTED
- `activate_approval()` → status = FOUNDER_APPROVED
- `find_approval()` validates: recipient, stage, subject, body hash, send window
- Atlas CANNOT self-approve

### Production Law

1. **Gmail proves communication.** NO VERIFIED GMAIL MESSAGE ID = NO STAGE ADVANCEMENT
2. **SENT_RECONCILIATION_REQUIRED** = repair records, NEVER resend
3. **PENDING DOES NOT MEAN FAILED.** Check time before intervening in scheduled jobs.
4. **All gates fail closed.** UNKNOWN never equals PASS.

### Recovery Sequence (after model/provider failure)

1. Load this document and `knowledge/production-operating-protocol.md`
2. Verify Gmail connectivity: `python3 -c "from scripts.canonical_send import _get_gmail_token; print(_get_gmail_token())"`
3. Check for pending approved sends in `data/founder-approvals/approved/`
4. Reconcile Airtable against Gmail Sent for any gap
5. Resume monitoring — do NOT resend anything without Founder Approval
