## Context

PandaDoc share pages are React SPAs that render content via contenteditable elements invisible to standard DOM queries. `pandadoc-extract.py` v1 used `document.body.innerText` via `Runtime.evaluate` and returned empty results for all PandaDoc URLs. The extraction was consistently failing.

## Decision

1. Rewrite `pandadoc-extract.py` to use `Accessibility.getFullAXTree` (Chrome DevTools Protocol) as the primary extraction method.
2. Retain `document.body.innerText` as fallback only.
3. Six primary fields certified: customer_name, customer_email, pandadoc_number, quote_value, address, quote_date.
4. Two additional fields recovered: expiry_date, gst.
