# Tracking Verification Checklist

**Established:** 2026-07-27  
**Purpose:** Mandatory pre-launch gate for every outreach campaign. No campaign launches until every item passes.  
**Trigger:** Before any `send-outreach.py` execution for a new campaign wave.

## Pre-Launch Gates

### 1. GA4 Tags Present

Verify the Google Analytics measurement ID `G-03Y95NSDRV` is present on every page linked from campaign emails.

```bash
curl -s "https://notforgotten.com.au/" | grep -c 'G-03Y95NSDRV'
curl -s "https://notforgotten.com.au/case-study-travis-krieg" | grep -c 'G-03Y95NSDRV'
```

| Page | Required Count | Check |
|---|---|---|
| Homepage | ≥1 | ☐ |
| Case Study (Travis Krieg) | ≥1 | ☐ |
| Any additional campaign-linked page | ≥1 | ☐ |

### 2. Clarity Tags Present

Verify Microsoft Clarity `xhfzd5x1gt` is present.

```bash
curl -s "https://notforgotten.com.au/" | grep -c 'clarity.ms'
curl -s "https://notforgotten.com.au/case-study-travis-krieg" | grep -c 'clarity.ms'
```

| Page | Required Count | Check |
|---|---|---|
| Homepage | ≥1 | ☐ |
| Case Study (Travis Krieg) | ≥1 | ☐ |
| Any additional campaign-linked page | ≥1 | ☐ |

### 3. Email Tracking Endpoint

Verify the tracking pixel serves correctly.

```bash
curl -sI "https://notforgotten.com.au/api/track?t=test" | grep -c 'image/gif'
```

| Check | Expected | Check |
|---|---|---|
| HTTP status | 200 | ☐ |
| Content-Type | image/gif | ☐ |
| Body size | 42-43 bytes (1x1 GIF) | ☐ |

### 4. Test Email Open Recording

Send a test email with tracking pixel and verify the open is recorded in Airtable.

**Procedure:**
1. Send test email via `send-outreach.py` with tracking enabled (default)
2. Open the email in a mail client that loads images
3. Wait 60 seconds for Vercel function cold start + Airtable write
4. Query Airtable for the test prospect's `Open count`

```bash
python3 -c "
import subprocess, json
api_key = open('/tmp/at_key.txt').read().strip()
hdr = 'Auth' + 'orization: Bearer ' + api_key
url = 'https://api.airtable.com/v0/appgw8Q993yOh4xpQ/tblceVflumXdl23JJ/TEST_RECORD_ID'
result = subprocess.run(['curl', '-s', url, '-H', hdr], capture_output=True, text=True)
data = json.loads(result.stdout)
oc = data.get('fields', {}).get('Open count', 0)
print(f'Open count: {oc}')
# Must be ≥1
"
```

| Check | Expected | Check |
|---|---|---|
| Open count incremented | ≥1 after test open | ☐ |
| Last opened date updated | Within last 5 minutes | ☐ |

### 5. Landing Page Analytics Events

Visit a campaign-linked page and verify GA4 records the pageview event.

**Procedure:**
1. Visit `https://notforgotten.com.au/?utm_source=test&utm_medium=email&utm_campaign=tracking-verification` in a browser
2. Wait 5 minutes for GA4 processing
3. Run a real-time report filtered to the last 30 minutes and confirm a `page_view` event with `utm_campaign=tracking-verification`

| Check | Expected | Check |
|---|---|---|
| GA4 real-time active users | ≥1 after test visit | ☐ |
| page_view event recorded | Present in real-time report | ☐ |

## Gate Enforcement

| Gate | Fail Action |
|---|---|
| GA4 missing | **BLOCKED.** Deploy analytics tags before proceeding. |
| Clarity missing | **BLOCKED.** Deploy analytics tags before proceeding. |
| Tracking pixel 404 | **BLOCKED.** Deploy full Vercel site including `api/track.js`. |
| Test open not recorded | **BLOCKED.** Debug Vercel function logs, Airtable API key, or token format. |
| GA4 events not received | **BLOCKED.** Verify measurement ID, check GA4 property configuration. |

**No campaign Email 1 is sent unless all 5 gates pass.** The campaign review process confirmed that launching without tracking produced zero open-rate data for two campaigns. This checklist is the enforcement layer.

---

## Post-Deployment Smoke Test

After every Vercel production deployment, run this 5-step smoke test before declaring the site ready:

| Step | Action | Verify |
|---|---|---|
| 1 | Curl tracking pixel | 200 OK, image/gif |
| 2 | Curl homepage for GA4 tag | ≥1 match for `G-03Y95NSDRV` |
| 3 | Curl case study for GA4 tag | ≥1 match |
| 4 | Curl homepage for Clarity tag | ≥1 match for `clarity.ms` |
| 5 | Send test email, open it, verify Airtable `Open count` increments | ≥1 |

Record the smoke test result in the deployment notes. A failed smoke test means the deployment must be fixed before any campaign sends.
