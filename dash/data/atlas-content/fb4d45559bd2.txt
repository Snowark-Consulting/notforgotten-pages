## Decision

Phase 1 Production Cutover is CERTIFIED. The Canonical Send Authority (`scripts/canonical-send.py`) is now the sole production customer Gmail send path for Not Forgotten Systems.

## Architecture

- **Canonical Send Authority:** `scripts/canonical-send.py` — sole `messages/send` call in active production
- **11-Gate Pipeline:** Classification (-1) → Idempotency (0) → Founder Approval (1) → Pre-Send (2) → Duplicate (3) → Gmail (4) → Verify (5) → Messages (6) → Evidence (7) → State (8) → Read-Back (9) → Reconciliation (10)
- **Send Classification:** CUSTOMER (journey mandatory) | SYSTEM_INTERNAL | TEST_NON_PRODUCTION
- **Fail-Closed:** All gates. UNKNOWN = BLOCKED.
- **Idempotency:** SENT_RECONCILIATION_REQUIRED = repair records, NEVER resend.

## Scheduling Incident

On 2026-08-08, Atlas manually executed the Jeremy/Skyla/Jordan workflow at 7:17 AM before its 9:00 AM scheduled time. The cron DID NOT fail — Atlas incorrectly interpreted PENDING as a problem.

**Permanent Lesson:** PENDING DOES NOT MEAN FAILED. Before intervening in any scheduled workflow: establish CURRENT TIME, SCHEDULED TIME, TIMEZONE, JOB STATUS. A healthy pending job must remain untouched.

## Architectural Principle

Atlas reasons, recommends, drafts, prepares. Deterministic code gates decide execution. Safety rules enforced architecturally, not via model memory.
