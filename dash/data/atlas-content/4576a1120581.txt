## 7. Customer Context Gate enforcement (Part 7)

Minimum safe change to `canonical-send.py` (and `create_approval_request`/`activate_approval`):

- An approval/send artefact must carry a `context_gate` object: `{a_h_completed: true,
  customer_experience_test: "PASS", next_action: "EMAIL", contact_today_reason: "...",
  commercial_state: "...", evidence_refs: [...]}`.
- `canonical_send()` refuses execution (Gate -2) if this object is absent or `customer_experience_test != "PASS"`.
- The object must be non-trivial (a structured brief, not a bare boolean Atlas can flip). Atlas
  sets it only after actually completing the A–H brief. Founder approval remains a separate gate.

This is minimum effective enforcement: one new gate + one artefact field. Not a rebuild.
