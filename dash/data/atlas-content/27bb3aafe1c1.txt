# Decision: Permanent Initial Customer Email Law (2026-08-12)

> NO INITIAL CUSTOMER EMAIL MAY BE DRAFTED FROM MEMORY. 13-gate pipeline. Canonical template enforcement. Variable substitution only.

**Status:** PERMANENT — Founder Authority
**Established:** 2026-08-12
**Trigger:** QPaint Email 1 drafts generated from memory instead of canonical template

## Permanent Law

NO INITIAL CUSTOMER EMAIL MAY BE DRAFTED FROM MEMORY.

Before generating any first-touch customer communication:

IDENTIFY CLIENT → IDENTIFY COMMUNICATION TYPE → RETRIEVE CURRENT APPROVED PROTOCOL → RETRIEVE CURRENT CANONICAL TEMPLATE → VERIFY CUSTOMER ELIGIBILITY → CHECK CUSTOMER HISTORY → CHECK REPEAT-CONTACT STATUS → CHECK CLIENT-SPECIFIC INSTRUCTIONS → LOAD SOURCE EVIDENCE → SUBSTITUTE APPROVED VARIABLES ONLY → RUN TEMPLATE COMPLIANCE CERTIFICATION → PRESENT FOR FOUNDER APPROVAL → SEND ONLY IF AUTHORITY EXISTS

Never: CUSTOMER APPEARS ELIGIBLE → GENERATE A REASONABLE EMAIL FROM MEMORY.

- DRAFTED ≠ COMPLIANT
- COMPLIANT ≠ APPROVED
