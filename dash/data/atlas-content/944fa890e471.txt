# GitHub backup re-homed + live-secret/PII cleanup

> The vault backup moved to a private repo as a clean snapshot, leaving 9 live credential classes in the old history still to rotate.

## What changed

The nightly vault backup (`bin/nightly-backup.sh`, cron `d998982d2e15`) moved from
`Snowark-Consulting/client-notforgotten` (dead `hancockjluke` PAT) to a new private repo
**`Hardstaff08/notforgotten-vault`** under James's account.

- `origin` rewired to `https://Hardstaff08:<ATLAS_GITHUB_TOKEN>@github.com/Hardstaff08/notforgotten-vault.git`
- Clean single-commit snapshot pushed (no dirty history): 2,511 files, ~450 KB.
- Verified: repo `private=true`, remote tree clean (no `.env`/`.pat`/`.db`/`token.json`/`backups/`/`data/`/`tmp/`/`reports/`).

## Why not full history

The old repo's 591 MB `.git` history contained a full `.env.bak` (all live tokens), a Gmail
OAuth token backup, a full `state.db` backup (session transcripts = PII), and password hashes.
Pushing that history would have propagated live secrets + client PII into a new repo. A clean
snapshot was the safe choice.
