## How to use

1. **Agent discovers a fix** → appends to own `learnings/LEARNINGS.md` (existing process).
2. **Nightly consolidation** → notes new learning in `notes/<date>.md` with `**New learning:** <title>`.
3. **Winston's morning harvest** → polls all agents' daily notes, extracts new learnings, formalizes into a card update, pushes to deploy kit, and redistributes to all agents.
4. **Every agent** → loads this catalogue at boot. Before touching a domain, checks the trigger column. If keyword matches, loads the card.

## Card format

Each card in `cards/<domain>.md`:
```markdown
# <domain> — Known Traps

## TRAP — short title
**When:** what action triggers this
**Symptom:** what breaks
**Fix:** exact working approach
```
